# API Documentation

> Detailed OpenAPI (Swagger) descriptions are auto-generated by FastAPI at `http://localhost:<PORT>/docs` for each module.

## Core Endpoints Overview

### `auth-service` (Port: 8000)
- `POST /api/auth/register` - Create a new user (admin/caregiver).
- `POST /api/auth/login` - Authenticate and return a JWT access token.
- `GET /api/auth/me` - Get current user profile (requires JWT).

### `face-verification` (Port: 8001)
- `POST /api/face/verify` - Takes a base64 frame, returns a boolean match and identification.
- `GET /api/face/logs` - Retrieves history of face verification events.
- `GET /api/face/authorized` - Retrieves the list of authorized individuals.

### `tracking-geofencing` (Port: 8002)
- `POST /api/tracking/zones` - Define a new polygon geofence zone.
- `GET /api/tracking/zones` - Retrieve all configured zones.
- `GET /api/tracking/history` - Retrieve tracking logs and zone breaches.

### `anomaly-detection` (Port: 8003)
- `POST /api/anomaly/detect` - Takes a base64 frame, returns anomaly status (e.g., fall detected).
- `GET /api/anomaly/history` - Retrieve anomaly occurrence logs.
- `GET /api/anomaly/model-status` - Check if LSTM/Autoencoder models are loaded.

### `schedule-monitoring` (Port: 8004)
- `GET /api/schedule/` - Retrieve the expected daily routine.
- `GET /api/schedule/deviations` - Retrieve instances where actual behavior missed routine marks.
- `POST /api/schedule/reports` - Generate daily summary reports.

### `gateway-dashboard` (Port: 8005)
- `GET /api/gateway/overview` - Aggregates health checks (`/health`) from all other running backends.
- `GET /api/gateway/alerts` - Pulls the latest 20 alerts from all module databases and sorts by timestamp.
